# Rehearsal Scheduler
This app is meant for people in the community theatre world who struggle to create a rehearsal schedule for their upcoming production. Put in your production information, upload your script, add your cast/crew schedule conflicts, and automatically generate a schedule that you can customize and export!

This is a work in progress, built with React + TypeScript on Vite, utilizing Tailwind for styling and Shadcn/ui for the underlying component library.
